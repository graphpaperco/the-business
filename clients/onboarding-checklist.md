# Client Onboarding Checklist - Graph Paper LLC

Use this checklist to ensure smooth onboarding for every new client engagement.

---

## Pre-Contract (Sales Phase)

### Initial Contact & Discovery
- [ ] Initial consultation call completed
- [ ] Understand client's problem/opportunity
- [ ] Determine if project is good fit
- [ ] Ballpark budget and timeline discussed
- [ ] Decision-makers identified
- [ ] Client added to CRM/tracking system

### Proposal & Agreement
- [ ] Proposal drafted and sent
- [ ] Proposal questions answered
- [ ] Proposal approved/accepted
- [ ] Contract/MSA drafted
- [ ] SOW (Statement of Work) created
- [ ] Contract reviewed by client
- [ ] Contract signed by both parties
- [ ] Fully executed contract filed in `/legal/contracts/`

---

## Financial Setup

### Payment & Billing
- [ ] Invoice deposit/initial payment
- [ ] Deposit received and confirmed
- [ ] Client added to accounting system
- [ ] Payment terms confirmed (Net 15, etc.)
- [ ] Payment method established (ACH, check, credit card)
- [ ] Billing contact information confirmed
- [ ] Invoicing schedule set up
- [ ] If retainer: Auto-recurring invoice created

### Project Tracking
- [ ] Project created in time tracking software
- [ ] Budget/hours allocated in system
- [ ] Expense tracking enabled if applicable

---

## Communication Setup

### Contact Information
- [ ] Primary contact name and email
- [ ] Secondary/backup contact
- [ ] Technical contacts (if applicable)
- [ ] Decision-maker contacts
- [ ] Stakeholder list created

### Communication Channels
- [ ] Email thread initiated
- [ ] Slack/Teams channel created (if using)
- [ ] Video call platform confirmed (Zoom, Google Meet, etc.)
- [ ] Shared calendar created for meetings
- [ ] Preferred communication methods documented
- [ ] Response time expectations set
- [ ] Meeting cadence established (weekly, bi-weekly, etc.)

---

## Project Management Setup

### Tools & Access
- [ ] Project management tool selected (Jira, Asana, Trello, etc.)
- [ ] Project created in PM tool
- [ ] Client given access to PM tool
- [ ] Shared documentation space created (Google Drive, Notion, etc.)
- [ ] File sharing permissions configured
- [ ] Client invited to relevant tools

### Project Planning
- [ ] Project plan/roadmap created
- [ ] Milestones and deadlines confirmed
- [ ] Task breakdown completed
- [ ] Dependencies identified
- [ ] Risk assessment documented
- [ ] Success criteria defined

---

## Technical Setup

### Access & Credentials
- [ ] Required system access identified
- [ ] Account access requested from client
- [ ] API keys or credentials received
- [ ] VPN access configured (if needed)
- [ ] Repository access granted (GitHub, GitLab, etc.)
- [ ] Development environment access
- [ ] Staging/production environment access
- [ ] Admin credentials secured in password manager

### Development Environment
- [ ] Code repository created
- [ ] Branching strategy defined
- [ ] CI/CD pipeline set up (if applicable)
- [ ] Development environment configured
- [ ] Testing environment set up
- [ ] Client added as collaborator to repository

### Security & Compliance
- [ ] NDA signed (if required)
- [ ] Security requirements documented
- [ ] Compliance requirements identified (HIPAA, SOC2, etc.)
- [ ] Data handling procedures established
- [ ] Backup procedures configured

---

### Pre-Kickoff Preparation
- [ ] Kickoff agenda created
- [ ] Kickoff meeting scheduled

- [ ] Questions/topics for discussion collected

- [ ] Introductions completed
- [ ] Project goals and scope reviewed
- [ ] Timeline and milestones confirmed
- [ ] Roles and responsibilities clarified
- [ ] Communication plan reviewed
- [ ] Questions answered

### Post-Kickoff
- [ ] Kickoff meeting notes documented
- [ ] Action items distributed
- [ ] First milestone/task started
- [ ] Kickoff summary email sent
- [ ] Update project status to "Active"

## Red Flags to Watch For

During onboarding, watch for these warning signs:

### Communication Issues
- [ ] ⚠️ Slow response times from client
- [ ] ⚠️ Unclear decision-making authority
- [ ] ⚠️ Stakeholders not aligned on goals
- [ ] ⚠️ Scope creep in early conversations

### Financial Issues
- [ ] ⚠️ Delayed deposit payment
- [ ] ⚠️ Pushback on payment terms
- [ ] ⚠️ Unclear budget authority

### Technical Issues
- [ ] ⚠️ Delayed access to systems
- [ ] ⚠️ Lack of technical documentation
- [ ] ⚠️ Unclear technical requirements
- [ ] ⚠️ Legacy systems or technical debt not disclosed

**If you notice red flags:** Address immediately, document concerns, and escalate if necessary.
