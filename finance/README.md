# Finance

This directory contains all finance-related documentation, processes, and financial records.

## Purpose

The finance function is responsible for managing the company's financial health, including:
- Financial planning and analysis
- Budgeting and forecasting
- Accounting and bookkeeping
- Financial reporting
- Cash flow management

## Key Documents

- **CLAUDE.md** - Detailed workflows and processes for finance operations
- **budgets/** - Annual budgets and forecasts
- **financial-statements/** - Monthly, quarterly, and annual financial statements
- **models/** - Financial models and planning spreadsheets
- **policies/** - Financial policies and procedures
- **reports/** - Management reports and board packages
- **tax/** - Tax returns and planning documents
