# Investor Updates

This directory contains all monthly investor update communications.

## Purpose

Regular monthly updates keep investors informed about company progress, challenges, and how they can help. Consistent communication builds trust and maintains strong investor relationships.

## Structure

```
investor-updates/
├── templates/
│   └── monthly-update-template.md
├── 2024/
├── 2025/
├── 2026/
└── README.md (this file)
```

## Guidelines

### Timing
- Send on the same day each month (e.g., first Monday)
- Aim for consistency to build a cadence investors expect
- Send even if there's not much news - consistency matters

### Content
- Use the template in [templates/monthly-update-template.md](templates/monthly-update-template.md)
- Keep updates concise (1-2 pages)
- Be transparent about both wins and challenges
- Include specific "asks" for how investors can help
- Back up claims with metrics and data

### Distribution
- Send to all investors and shareholders
- BCC for privacy (or use investor update platform)
- Archive each update in the appropriate year folder
- Name files: `YYYY-MM-update.md` (e.g., `2026-01-update.md`)

## Best Practices

1. **Be Transparent** - Share challenges, not just wins
2. **Be Specific** - Use concrete metrics and examples
3. **Be Concise** - Respect investors' time
4. **Be Consistent** - Same day each month
5. **Be Forward-Looking** - Include plans and milestones
6. **Be Appreciative** - Thank investors for their support
7. **Be Actionable** - Include specific asks

## Template Sections

- **Executive Summary** - One paragraph overview
- **Key Metrics** - Core financial, growth, product, and team metrics
- **Highlights** - Top 3 wins this month
- **Challenges** - Top 2-3 issues and how you're addressing them
- **Focus for Next Month** - Top 3 priorities
- **Asks** - Specific ways investors can help

## Example Timeline

- **Day 1-3** of month: Collect metrics and highlights from teams
- **Day 4-5**: Draft update using template
- **Day 6**: Review with leadership team
- **Day 7**: Send to investors (e.g., first Monday)
