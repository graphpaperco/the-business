# Investor Relations

This directory contains all investor communications, updates, and board materials.

## Purpose

The investor relations function is responsible for maintaining strong relationships with investors and shareholders, including:
- Regular investor updates and communications
- Board meeting preparation
- Investor reporting and metrics
- Shareholder communication
- Board governance

## Key Documents

- **CLAUDE.md** - Detailed workflows and processes for investor relations
- **investor-updates/** - Monthly investor update emails
- **board-meetings/** - Board meeting materials, agendas, and presentations
- **board-materials/** - Corporate governance documents (minutes, consents, resolutions)
- **metrics-reporting/** - KPI dashboards and tracking
- **cap-table/** - Current capitalization table and ownership
