# Fundraising

This directory contains all fundraising materials, investor pipeline, and campaign resources.

## Purpose

The fundraising function is responsible for securing capital for the company, including:
- Fundraising strategy and planning
- Investor pipeline management
- Pitch deck development
- Data room preparation
- Term sheet negotiation
- Due diligence coordination

## Key Documents

- **CLAUDE.md** - Detailed workflows and processes for fundraising campaigns
- **pitch-decks/** - Current and archived pitch decks
- **data-room/** - Due diligence materials organized for investor review
- **investor-pipeline/** - Target investor lists and outreach tracking
- **term-sheets/** - Templates and negotiation documents
- **models/** - Financial projections and cap table
